📖 1. What is a Queue?

A Queue is a linear data structure that follows FIFO — First In, First Out.

🔗 6. Queue using Singly Linked List

A linked-list queue uses two pointers: FRONT points to the first node and REAR points to the last node.

Operation:
Start by ENQUEUE. The first node becomes both FRONT and REAR.
FRONT: first node value  |  REAR: last node value  |  ISEMPTY(): front == NULL  |  ISFULL(): no fixed capacity; failure can occur only if memory allocation fails.
Current OperationSTART
FRONTNULL
REARNULL

ENQUEUE — REAR

newNode->data = data;
newNode->next = NULL;

if (isEmpty(queue))
{
    queue->front = queue->rear = newNode;
}
else
{
    queue->rear->next = newNode;
    queue->rear = newNode;
}

DEQUEUE — FRONT

temp = queue->front;
data = temp->data;

queue->front = queue->front->next;

if (queue->front == NULL)
    queue->rear = NULL;

free(temp);
Think: SAVE → MOVE → FREE. If the last node is removed, both FRONT and REAR become NULL.

FRONT / REAR / ISEMPTY

int frontValue(struct Queue *queue)
{
    if (isEmpty(queue))
        return -1;

    return queue->front->data;
}

int rearValue(struct Queue *queue)
{
    if (isEmpty(queue))
        return -1;

    return queue->rear->data;
}

int isEmpty(struct Queue *queue)
{
    return (queue->front == NULL);
}

🔄 8. Queue Using Two Stacks

A queue can be implemented using two stacks. ENQUEUE is performed on Stack 1, while DEQUEUE/FRONT use Stack 2. When Stack 2 is empty, elements are transferred from Stack 1 to Stack 2.

Operation:
Start by ENQUEUE. New elements enter Stack 1.

void enqueue(int value)
{
    push(&stack1, value);

DEQUEUE — TRANSFER IF NEEDED

if (isEmpty(&stack2))
{
    while (!isEmpty(&stack1))
        push(&stack2, pop(&stack1));
}

return pop(&stack2);
Key idea: Stack 1 receives new elements. Stack 2 reverses their order, so the oldest element reaches the TOP of Stack 2 and can be removed first.

Complete C Program — Queue Using Two Stacks

#include <stdio.h>
#define MAX 100

int stack1[MAX], stack2[MAX];
int top1 = -1, top2 = -1;

int isEmpty1()
{
    return (top1 == -1);
}

int isEmpty2()
{
    return (top2 == -1);
}

void push1(int value)
{
    stack1[++top1] = value;
}

void push2(int value)
{
    stack2[++top2] = value;
}

int pop1()
{
    return stack1[top1--];
}

int pop2()
{
    return stack2[top2--];
}

void transfer()
{
    while (!isEmpty1())
        push2(pop1());
}

void enqueue(int value)
{
    if (top1 + top2 + 2 > MAX)
    {
        printf("Queue Overflow\n");
        return;
    }

    push1(value);
}

int dequeue()
{
    if (isEmpty1() && isEmpty2())
    {
        printf("Queue Underflow\n");
        return -1;
    }

    if (isEmpty2())
        transfer();

    return pop2();
}

int frontValue()
{
    if (isEmpty1() && isEmpty2())
        return -1;

    if (isEmpty2())
        transfer();

    return stack2[top2];
}

void display()
{
    int i;

    if (isEmpty1() && isEmpty2())
    {
        printf("Queue is empty.\n");
        return;
    }

    printf("Queue: ");

    for (i = top2; i >= 0; i--)
        printf("%d ", stack2[i]);

    for (i = 0; i <= top1; i++)
        printf("%d ", stack1[i]);

    printf("\n");
}

int main()
{
    int choice, value;

    while (1)
    {
        printf("\n--- QUEUE USING TWO STACKS ---\n");
        printf("1. ENQUEUE\n");
        printf("2. DEQUEUE\n");
        printf("3. FRONT\n");
        printf("4. DISPLAY\n");
        printf("5. ISEMPTY\n");
        printf("6. EXIT\n");
        printf("Enter choice: ");
        scanf("%d", &choice);

        switch (choice)
        {
            case 1:
                printf("Enter value: ");
                scanf("%d", &value);
                enqueue(value);
                break;

            case 2:
                value = dequeue();
                if (value != -1)
                    printf("Dequeued: %d\n", value);
                break;

            case 3:
                value = frontValue();
                if (value != -1)
                    printf("Front: %d\n", value);
                else
                    printf("Queue is empty.\n");
                break;

            case 4:
                display();
                break;

            case 5:
                printf("%s\n",
                       (isEmpty1() && isEmpty2()) ?
                       "Queue is empty." : "Queue is not empty.");
                break;

            case 6:
                return 0;

            default:
                printf("Invalid choice.\n");
        }
    }

    return 0;
}

✓ 9. Summary & Practice Questions

  • Queue follows FIFO — First In, First Out.
  • ENQUEUE adds an element at the REAR.
  • DEQUEUE removes an element from the FRONT.
  • FRONT / PEEK reads the first element without removing it.
  • REAR identifies the last element currently in the queue.
  • ISEMPTY() checks whether the queue contains no elements.
  • ISFULL() is mainly relevant to fixed-size array queues.
  • A linked-list queue normally maintains both FRONT and REAR.
  • In a linked-list queue, ENQUEUE happens at REAR and DEQUEUE happens at FRONT.
  • When the last linked-list node is removed, both FRONT and REAR become NULL.
  • Queue variants include Linear Queue, Circular Queue, Priority Queue, and Deque.
  • A queue can also be implemented using two stacks.
  • In a two-stack queue, Stack 1 receives new elements and Stack 2 provides the FIFO order.
“First In, First Out —
understand the order, then understand the implementation.”
