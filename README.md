# Queue Visualizer — Data Structures and Algorithms

An interactive web-based visualization for learning **Queue data structures and their implementations**.

The visualizer is designed for DSA teaching and classroom demonstrations, allowing students to perform queue operations and observe how the data structure changes visually.

## Features

### 1. What is a Queue?
- FIFO — First In, First Out
- Interactive real-life FIFO example
- Visual representation of people waiting in a queue

### 2. Queue Operations
Interactive operations including:

- ENQUEUE
- DEQUEUE
- FRONT / PEEK
- REAR
- ISEMPTY()
- ISFULL()
- DISPLAY

Students can enter their own values and observe the changes.

### 3. Queue vs Stack
Interactive comparison between:

- Queue — FIFO
- Stack — LIFO

Students can add and remove elements independently and observe:

- Queue FRONT
- Queue REAR
- Stack TOP

### 4. Types of Queue

Interactive visualizations for:

- Linear Queue
- Circular Queue
- Priority Queue
- Deque

### 5. Applications of Queue

Examples of queue usage in:

- CPU Scheduling
- Printer Scheduling
- Network Buffers
- Breadth First Search (BFS)
- Real-life waiting systems

### 6. Queue Using Linked List

Interactive visualization of a queue implemented using a singly linked list.

Operations include:

- ENQUEUE
- DEQUEUE
- FRONT
- REAR
- ISEMPTY()
- ISFULL()
- DISPLAY

The visualization shows:

- FRONT pointer
- REAR pointer
- Dynamic nodes
- Node connections

### 7. Queue Using Two Stacks

Interactive visualization showing how a FIFO queue can be implemented using two stacks.

- Stack 1 receives new elements.
- Stack 2 provides the FIFO order.
- Elements are transferred from Stack 1 to Stack 2 when required.

Operations include:

- ENQUEUE
- DEQUEUE
- FRONT
- ISEMPTY()
- DISPLAY

### 8. C Programs

The visualizer includes C implementations demonstrating the queue concepts discussed in the interactive sections.

### 9. Summary and Practice Questions

Important concepts are summarized along with practice questions covering:

- FIFO
- Queue operations
- Linked-list queues
- Circular queues
- Priority queues
- Deques
- Queue using two stacks
- Queue implementation in C
